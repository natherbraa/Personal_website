# الموقع الشخصي لنذير براء

هذا المشروع عبارة عن موقع شخصي تفاعلي ثلاثي الأبعاد لنذير براء، مصمم ومبرمج متعدد المهارات.

[![رفع على GitHub](https://img.shields.io/badge/رفع_على-GitHub-181717?style=for-the-badge&logo=github)](github-upload.md)

## المميزات

- تصميم عصري وتفاعلي باستخدام React و TypeScript
- تأثيرات ثلاثية الأبعاد باستخدام Three.js و React Three Fiber
- حركات وانتقالات سلسة باستخدام Framer Motion و GSAP
- تصميم متجاوب يعمل على جميع الأجهزة
- واجهة مستخدم سهلة الاستخدام وجذابة بصريًا
- نموذج اتصال مدمج مع EmailJS

## التقنيات المستخدمة

- **React**: مكتبة JavaScript لبناء واجهات المستخدم
- **TypeScript**: لغة برمجة قوية مبنية على JavaScript
- **Vite**: أداة بناء سريعة للتطوير الحديث
- **Three.js**: مكتبة JavaScript لإنشاء رسومات ثلاثية الأبعاد
- **React Three Fiber**: واجهة React لـ Three.js
- **Framer Motion**: مكتبة للرسوم المتحركة في React
- **GSAP**: مكتبة للرسوم المتحركة المتقدمة
- **EmailJS**: لإرسال رسائل البريد الإلكتروني من الموقع

## كيفية التشغيل

1. قم بتثبيت الاعتماديات:
   ```
   npm install
   ```

2. قم بتشغيل خادم التطوير:
   ```
   npm run dev
   ```

3. قم ببناء الإصدار النهائي:
   ```
   npm run build
   ```

4. يمكنك أيضًا فتح ملف `local-server.html` في المتصفح للحصول على تعليمات تفصيلية حول كيفية تشغيل المشروع محليًا.

## إعداد نموذج الاتصال

تم تحديث نموذج الاتصال لاستخدام EmailJS مع معرف الخدمة `service_63srk5k`. لإكمال الإعداد:

1. قم بإنشاء حساب على [EmailJS](https://www.emailjs.com/) إذا لم يكن لديك حساب بالفعل
2. قم بإنشاء قالب في حسابك واحصل على معرف القالب
3. قم بتحديث ملف `src/components/Contact.tsx` بمعرف القالب ومفتاح API العام الخاص بك:
   ```typescript
   emailjs.sendForm(
     'service_63srk5k',
     'YOUR_TEMPLATE_ID', // قم بتغييره إلى معرف القالب الخاص بك
     formRef.current,
     'YOUR_PUBLIC_KEY' // قم بتغييره إلى المفتاح العام الخاص بك
   )
   ```

## كيفية الوصول إلى الرسائل المرسلة

بعد إكمال إعداد EmailJS، يمكنك الوصول إلى الرسائل المرسلة من نموذج الاتصال عن طريق:

1. تسجيل الدخول إلى حسابك على [لوحة تحكم EmailJS](https://dashboard.emailjs.com/)
2. الانتقال إلى قسم "Email History" (سجل البريد الإلكتروني)
3. ستجد هناك جميع الرسائل التي تم إرسالها من نموذج الاتصال في موقعك

يمكنك أيضًا إعداد EmailJS لإعادة توجيه هذه الرسائل إلى بريدك الإلكتروني الشخصي.
