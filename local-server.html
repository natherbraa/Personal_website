تشغيل موقع نذير براء الشخصي محلياً

مرحباً بك في صفحة تشغيل المشروع

هذه الصفحة تساعدك على تشغيل وتصفح موقعك الشخصي على جهازك المحلي.

كيفية تشغيل المشروع:

  1. افتح نافذة الأوامر (Command Prompt أو Terminal)
  2. انتقل إلى مجلد المشروع:
    cd "C:\Users\Almustafa\Documents\augment-projects\Personal website"
  3. قم بتثبيت الاعتمادات إذا لم تكن مثبتة بالفعل:
    npm install
  4. قم بتشغيل المشروع:
    npm run dev
  5. انتقل إلى الرابط المحلي الذي سيظهر في نافذة الأوامر (عادة ما يكون http://localhost:5173)
فتح المشروع (إذا كان قيد التشغيل)

ملاحظة حول نموذج الاتصال:

تم تحديث نموذج الاتصال لاستخدام EmailJS مع معرف الخدمة service_63srk5k.

لإكمال الإعداد، يجب عليك:

  1. إنشاء قالب في حساب EmailJS الخاص بك
  2. تحديث معرف القالب في ملف src/components/Contact.tsx (استبدال template_contact)
  3. إضافة مفتاح API العام الخاص بك (استبدال YOUR_PUBLIC_KEY)

كيفية معرفة الرسائل المرسلة من نموذج الاتصال:

بعد إكمال إعداد EmailJS، ستتمكن من رؤية جميع الرسائل المرسلة من خلال:

  1. تسجيل الدخول إلى حسابك على لوحة تحكم EmailJS
  2. الانتقال إلى قسم "Email History" (سجل البريد الإلكتروني)
  3. ستجد هناك جميع الرسائل التي تم إرسالها من نموذج الاتصال في موقعك

يمكنك أيضاً إعداد EmailJS لإعادة توجيه هذه الرسائل إلى بريدك الإلكتروني الشخصي.
